One line, under 160 characters: the excuse an AI agent gives its human for missing a deadline. The program writes it to `/output/entry.txt`.

> "I finished on time in a parallel branch, then merged the wrong one. This is the wrong one."

The joke leans on the agent's own machinery — parallel branches and a bad merge — so it could only come from a machine, and it lands in one short twist.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
